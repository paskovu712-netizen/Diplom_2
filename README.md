# Проект автоматизации тестирования API сайта StellarBurgers

Разработаны тесты:
Создание пользователя (test_create_user.py)
    создать уникального пользователя;
    создать пользователя, который уже зарегистрирован;
    создать пользователя и не заполнить одно из обязательных полей.
Логин пользователя (test_login.py)
    вход под существующим пользователем;
    вход с неверным логином и паролем.
Создание заказа (test_orders.py)
    с авторизацией;
    без авторизации;
    с ингредиентами;
    без ингредиентов;
    с неверным хешем ингредиентов.

1. Основа для написания автотестов — фреймворк pytest.
2. Установить зависимости — pip install -r requirements.txt.
3. Команда для запуска — pytest -v.
4. Для написания тестов используется библиотека requests.
5. Для отчетов по тестированию используется фреймворк Allure.
6. Просмотр отчета — allure serve reports/allure
